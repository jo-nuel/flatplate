# FlatPlate

FlatPlate is a desktop meal-planning application that helps users organise seven days of meals and keep within a grocery budget.

## Features

- Create and manage a FlatPlate account.
- Add, edit, search, and filter recipes.
- View and update Coles and Woolworths prices.
- Import and export price-book records as CSV.
- Plan breakfast, lunch, and dinner for each day of the week.
- Merge recipe ingredients and calculate the estimated weekly cost.
- Compare the estimated spend with a selected grocery budget.
- Use a grouped shopping list, track purchases, and compare the remaining basket by store.
- Review cuisine spending, potential waste, and ML.NET price estimates in Insights.

## Run in Visual Studio

1. Open `FlatPlate.sln` in Visual Studio 2022.
2. Set `FlatPlate.App` as the startup project.
3. Select **Start** to build and run the application.

## How to Use

1. Create an account and verify your email address, then sign in.
2. Add or select recipes in the Recipe Library.
3. Open Weekly Planner and assign recipes to breakfast, lunch, or dinner.
4. Choose a store and set a weekly budget.
5. Review the Shopping List for combined ingredients and estimated costs.
6. Use Price Book to update prices or import price records.
7. Open Insights to compare stores and view spending summaries.
